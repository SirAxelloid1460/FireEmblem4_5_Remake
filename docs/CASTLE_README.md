# Sistema Castle/Base de Preparación - Fire Emblem 4/5 Remake

Sistema completo de preparación pre-batalla inspirado en Fire Emblem 4: Genealogy of the Holy War y Fire Emblem 5: Thracia 776.

## 📁 Archivos Incluidos

```
CastleBase.gd              - Sistema principal del castillo/base
ShopPanel.gd               - Tienda de items y armas
CastleFacilities.gd        - Arena, Convoy, Herrería, Fortune Teller, Promoción
castle_base.tscn           - Escena del castillo
```

## 🎮 Facilidades del Castillo

### 🏪 Tienda (Shop)
- **Compra de armas e items**
- Inventario variado: Espadas, Lanzas, Hachas, Arcos, Magia, Curativos
- Precios basados en Fire Emblem 4
- Visualización de stats de armas
- Sistema de oro compartido

### 📦 Convoy
- **Inventario del ejército**
- Transferencia entre unidades y convoy
- 5 items máximo por unidad
- Almacenamiento ilimitado

### ⚔️ Arena
- **Combates por EXP y oro**
- Oponentes según nivel
- Sistema de apuestas
- ¡Riesgo de muerte! (FE4 style)

### 🔨 Herrería
- Reparación de armas
- 10 oro por durabilidad

### 🔮 Fortune Teller
- Predicciones de combate
- Info de promoción

### ⭐ Promoción
- Nivel 20+ requerido
- Bonuses de stats
- Clases avanzadas

## 🚀 Flujo del Juego

```
Menú → Cinemática → CASTLE → Pre-Battle → Batalla
```
