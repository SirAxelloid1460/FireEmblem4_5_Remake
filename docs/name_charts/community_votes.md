# Votaciones de nombres — comunidad (FE4/FE5)

Resultados de dos encuestas a la comunidad (Google Forms) sobre qué grafía usar
para varios nombres del proyecto. Se conservan **tal cual**; el ganador es la
opción más votada. Fuente: hojas de cálculo propias del autor.

> En empates o pluralidades muy débiles se mantiene el nombre que ya usaba el
> proyecto. Ej.: **Boldor** (empate 7–7) y **Andrey** (Andrei solo 5/15) se
> **mantienen**.
